物语工坊 · Windows 双击运行版

适用：Windows 10/11 64 位电脑。无需安装 Node.js、npm 或其他开发工具。

1. 将整个 ZIP 压缩包解压到一个文件夹。不要直接在压缩包里双击。
2. 双击「Start Studio.bat」。首次启动可能需要几十秒。黑色窗口保持开启。
3. 默认浏览器会自动打开物语工坊。若没有自动打开，请复制黑色窗口里显示的本地地址到浏览器。
4. 在页面里粘贴自己的 OpenAI API 密钥，再上传同一产品的两张照片，点击生成。
5. 图片完成后可单张下载或打包下载。关闭黑色窗口即可停止网站。

图片生成需要网络连接和有可用额度的 OpenAI API 密钥，服务商会按用量收费。密钥会通过本机网站发送给 OpenAI，不写入压缩包或电脑文件；刷新页面后需要重新粘贴。请不要把密钥发给别人。

如果 Windows 显示安全提示，请确认压缩包来自你自己下载的物语工坊文件。本包内的 node.exe 来自 Node.js 官方发行包，打包时已按官方 SHA256 校验。不要从来源不明的网站下载替代运行文件。
